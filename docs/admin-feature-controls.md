## 控制邊界

這些是前台功能發布／顯示開關，並不是後端 API 授權。關閉畫面後，既有後端公開或登入 API 仍依原有授權規則執行；不能把 CSS 隱藏當成權限封鎖。管理 API 則驗證獨立管理者 session。黑名單是真正的帳號管制，會撤銷使用者既有 session。

共用資料收集、每日排程、Secrets、服務端點、模型部署與資料庫維護仍由部署設定／維運流程控制，本次沒有讓管理者頁面直接改寫它們。已開始的 API 請求與使用者先前啟用的自動 Podcast 任務，不會因顯示開關而自動取消。

## 使用者自行決定的項目

| 項目 | 控制者 |
| --- | --- |
| 台股／美股追蹤公司名單 | 登入使用者；市場開關只決定是否顯示市場主畫面 |
| 追蹤清單與新聞同步開關 | 登入使用者；關閉市場不刪除／改寫同步資料 |
| API 金鑰、模型、供應商、端點與本機代理 | 使用者於各裝置設定 |
| MA 週期、圖表範圍、日期、主題 | 使用者於各裝置設定 |
| Podcast 自動處理、選擇集數、略過／重試 | 使用者自行設定；顯示開關不代表停止既有任務 |
| 庫存資料、逐字稿與 AI 成果 | 原有帳號／裝置歸屬規則；管理者顯示設定不編輯其內容 |

## 已確認的修正與驗證

- 16 個管理者葉節點均有前台 selector 對應與說明；全站與個別使用者共用功能目錄。
- 同名功能的控制分離：券商報告與庫存、新聞與 Podcast。
- 動態新增的畫面使用全頁規則套用開關，不因局部重繪重新出現。
- 避免固定 30 秒更新設定時反覆重繪，只有旗標內容改變時重繪。
- 全站關閉後可為個別測試使用者覆寫開啟；使用者黑名單與功能顯示維持獨立。
